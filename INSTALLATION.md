# Установка и эксплуатация комплекса обнаружения пожаров

## 1. Подключение оборудования

1. При отключённом питании подключите к Orange Pi тепловизор и курсовую камеру по USB. Используйте те же USB-разъёмы при каждом запуске.
2. Подключите Orange Pi к бортовой сети Ethernet. При необходимости подключите автопилот к UART-разъёму MAVLink.
3. Подключите штатный блок питания Orange Pi и включите питание. Дождитесь загрузки системы.

## 2. Установка ПО

На Orange Pi с Ubuntu 20.04 и ROS Noetic выполните:

```bash
mkdir -p ~/catkin_ws/src
cd ~/catkin_ws/src
git clone https://github.com/LaPidus42/ROSCOSMOS-HI-TECH-2026-AERIAL-ROBOTICS.git
ln -s ROSCOSMOS-HI-TECH-2026-AERIAL-ROBOTICS/fire_detection_ros_rknn fire_detection_ros_rknn_slop2
pip3 install -r fire_detection_ros_rknn_slop2/requirements.txt
cd ~/catkin_ws
rosdep install --from-paths src --ignore-src -r -y
catkin_make
```

Модель детекции уже находится в каталоге `fire_detection_ros_rknn_slop2/models/`.

## 3. Запуск и проверка

```bash
source /opt/ros/noetic/setup.bash
source ~/catkin_ws/devel/setup.bash
roslaunch fire_detection_ros_rknn_slop2 fire_system2.launch vehicle:=vtol
```

На компьютере оператора откройте в браузере `http://192.168.1.20:8080`. Установка выполнена правильно, если в интерфейсе отображаются оба видеопотока, а обнаруженные объекты выделяются рамками и появляются на карте и в журнале.

## 4. Штатная работа

1. Откройте видеопотоки тепловизора и курсовой камеры в веб-интерфейсе.
2. Наблюдайте за изображением: детекция выполняется автоматически, найденные объекты выделяются рамками.
3. При наличии навигационных данных просматривайте координаты объектов на карте; результаты работы просматривайте во вкладке «Журнал».

## 5. Безопасное завершение

В терминале запуска нажмите `Ctrl+C`, выполните `sudo poweroff`, дождитесь выключения Orange Pi и только затем отключите питание.

## 6. Типовая ошибка: веб-интерфейс не открывается

1. Убедитесь, что Orange Pi включён, а компьютер оператора подключён к той же сети.
2. На Orange Pi выполните `hostname -I` и откройте `http://<полученный IP-адрес>:8080`.
3. Если страница недоступна, остановите ПО сочетанием `Ctrl+C` и повторите запуск из раздела 3, затем обновите страницу браузера.
