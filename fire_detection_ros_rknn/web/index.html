    С дрона

    Взять изображение карты, которое рисует узел aruco_map, и файл карты маркеров, по которой дрон сейчас летает. Изображение сразу выставляется по маркерам.

    Изображение площадки

    PNG, JPEG или WebP: карта ArUco-маркеров, схема зала или снимок сверху.

    Карта маркеров

    Файл в формате aruco_pose (как у Clover): строка на маркер, id размер x y [z rot_z …], координаты центра в метрах. Маркеры рисуются точно по координатам, поэтому по ним удобно выставить изображение.

    Совмещение

    Меняйте ширину и угол, пока нарисованные маркеры не лягут на маркеры изображения. Без файла карты: поставьте дрон над маркером с известными координатами и двигайте изображение, пока метка дрона не окажется на нём.
